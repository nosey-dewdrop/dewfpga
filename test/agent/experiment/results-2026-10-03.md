# Project-guidance experiment, replacement batch v3

Both arms repaired all eight fixtures. This batch shows no repair-success advantage
for project guidance. With one attempt per fixture and arm, it cannot establish a
reliable rate, speed improvement, or general claim about coding agents.

| Observed measure | Plain | Guided |
| --- | ---: | ---: |
| Repair acceptance | 8/8 | 8/8 |
| Tool calls | 50 | 41 |
| Claude process seconds, excluding acceptance | 516.87 | 550.92 |
| Bash calls containing `--json` | 0 | 13 |
| Outside-project temporary-backup deviations | 0 | 1 |

These are observations from this run, not token or cost measurements. A Bash call
can contain multiple CLI commands; the JSON column is not an invocation count.
Some guided agents chose text output despite the instructions.

All 16 fresh sessions initialized with `claude-fable-5-1`, in the balanced order
recorded in [the machine-readable results](results-2026-10-03.json). Each got one
attempt with a 600-second allowance; none was resumed or rerun. The same frozen
CLI, fixtures, judges and guidance were used throughout. Root rechecked all 63
frozen harness files, all 16 acceptance logs, model identity, and unique sessions.
There were 130 top-level acceptance checks: source/constraint preservation, fresh
simulation and bitstream builds, testbench mutation checks, port equality, and
netlist equivalence. All passed; there was no skipped equivalence check or flash.

## Isolation correction and remaining limits

The [previous batch](invalid-results-2026-10-03.md) is retained as an invalid
comparison. It placed guidance above both arms; a plain agent demonstrably read
it. No cell from that batch contributes to these results.

In v3, guidance lived in a sibling folder and was copied only into guided projects.
The launcher checked lexical and resolved ancestors before each call. An injected
ancestor guide made the actual dry run abort before any model call; after removal,
16 new cells were launched. Root inspected all tool inputs and scanned tool outputs
for guidance and harness paths. No plain-arm guide or reference read was observed.
The same user-level configuration and hooks remained available to both arms; this
is not a clean-machine or filesystem-sandbox experiment.

One guided agent violated the project-only path rule by writing its own `top.sv`
to a temporary backup outside the project, checking a mutation, and restoring the
backup. The transcript shows the write before the read and no outside solution or
reference access. This deviation is retained in the result, not silently treated
as strict protocol compliance.

Fixtures 1 and 2 are automatic CLI-repair controls. Seven reference testbenches
were also visible in the input fixture; only fixture 7 had an unseen reference
testbench. The wrong-design set is finite. Process time varies with machine load
and shell mistakes; the smaller tool-call count does not establish an efficiency
benefit. The full invocation, per-cell counts, limitations and checks are recorded
in the JSON file. Private raw transcripts remain local because they include paths
and user-level environment details.
