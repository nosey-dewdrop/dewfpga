ERROR [wave-viewer-missing]: Surfer is not installed, so the waveform cannot open in it. Fix: brew install surfer, or open it in the browser: dewfpga sim tb_mux2 --wave=browser

Why does it happen?

dewfpga sim --wave (and --wave=both) open the waveform in Surfer, a waveform viewer from Homebrew. dewfpga install installs it since 4 November 2026; an install from before that has no Surfer, and dewfpga check shows its row as MISSING. dewfpga looks for it before the simulation runs, so nothing is simulated for a window that cannot open.

What is the fix?

Install Surfer (or run dewfpga install again, which adds it), then run the same command again:

brew install surfer

Or open the waveform in the browser page instead, which needs nothing installed:

dewfpga sim --wave=browser

Which command prints it?

  • dewfpga sim
  • dewfpga wave
