Why does it happen?

A syntax error (a missing end, a default outside its case), or a construct in a .v file that Verilog-2005 lacks (logic above: see v-is-verilog-2005), or SystemVerilog the readers do not build yet. The usual ones and what to write instead are in the guide's section 8.

What is the fix?

Read yosys-slang's message and the caret; fix the first one, the later ones often follow from it. A .v file holding SystemVerilog:

mv blink.v blink.sv
