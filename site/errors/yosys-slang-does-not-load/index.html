Why does it happen?

yosys-slang is a shared library that links against yosys' own headers and ABI; a new yosys from brew changes them, and the plugin fails to load. Without it, a design that yosys' own reader refuses (interfaces, unpacked arrays, foreach ...) stops with second-reader-missing.

What is the fix?

dewfpga install
