Why does it happen?

The Basys3's chip has 20800 LUTs and 41600 flip-flops. A large memory without ram_style = "block" is built from LUTs; a wide divider or multiplier in one cycle takes thousands. A cell type that is not a chip resource is one of internal-tristate, wired-net, power-operator or empty-module, named as such.

What is the fix?

top.log lists the counts per cell type. Ask for a block RAM, narrow the data, share the operator over cycles.

(* ram_style = "block" *) logic [7:0] mem [0:4095];
