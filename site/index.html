write it in your own editor
cs223_lab2.sv

      
run the testbench
dewfpga sim tb_room_monitor
tb_room_monitor: 4096 cases, 0 errors

      
open the waveform in surfer
dewfpga sim tb_room_monitor --wave
waveform: tb_room_monitor.vcd, simulated by Icarus Verilog 13.0 (stable), opened in Surfer 0.7.0

      
build it and load the board
dewfpga flash top_monitor
top_monitor.bit  2.2 MB
4.1 s from .sv to .bit on an m2 with 8 gb

    

  

  






  

    

      

        

        

      

    

    

      
the board

      
a basys 3 running assign led = sw. flip a switch or click an led.


module top(input  logic [15:0] sw,
           output logic [15:0] led,
           output logic [6:0]  seg,
           output logic [3:0]  an);
    assign led = sw;
    // a 0 lights a segment and a digit
    assign seg = ~sw[6:0];
    assign an  = ~sw[15:12];
endmodule

      
swledsegan

      
sw, led, btn, seg, an and clk find their pins on their own, no pin file

      
slide the board sideways for every switch

    

  






  

    
cli
every command

    
install in one line, about 4 minutes, 0.3 gb on disk. vivado asks for 50 to 100 gb.

    
    

        
# install the toolchain, the same line updates it
%curl -fsSL https://nosey-dewdrop.github.io/dewfpga/install | bash

        
# runs the testbench
%dewfpga sim tb_room_monitor

        
# opens the waveform in surfer
%dewfpga sim tb_room_monitor --wave

        
# loads it onto the board
%dewfpga flash top_monitor
