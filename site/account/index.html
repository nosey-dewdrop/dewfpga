What can you do with the account?

rightwhat it does here
see the dataDownloads a JSON file with the dewfpga account record and the newsletter subscriptions linked to it.
deleteRemoves the dewfpga account record and the newsletter subscriptions linked to it, then signs out this session. It does not delete the shared sign-in identity (see below) and does not sign out other devices or apps.
sign outEnds this session only: the tab forgets it and the sign-in service revokes it. Other devices and other apps using the same sign-in stay signed in.

What is stored for an account?

wherewhatdeleted by
dewfpga account recordthe sign-in's user id, the time the record was created, a premium start time (empty, nothing is sold)the Delete button above
newsletter subscriptions linked to the accountthe rows from the newsletter that were confirmed or linked while signed inthe Delete button above
newsletter subscriptions made without signing innot linked to the account, not shown in the export, not deleted herethe unsubscribe link in any mail (the row is removed by the operator's cleanup, at the earliest 30 days later)
shared sign-in identity (Supabase Auth)email address, sign-in times, the magic-link mail log; shared with other projects of the same operatornot this page; removing the identity is a separate operator process, ask the operator

The magic-link mail itself is sent by Supabase Auth through the mail provider configured in the operator's Supabase project. The shared stylesheet of this site loads fonts from Google Fonts, so opening the page requests them from Google; the hosting (GitHub Pages) and Supabase keep their own request logs under their own terms. The sign-in email shown above is read from the session and used only to display it; nothing is linked or deleted by matching an email address.
