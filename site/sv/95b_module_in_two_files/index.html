Which error pages explain the messages?

  • module-defined-twice: Two files in the folder declare the same module; the tools would take the last one read, so a backup could be built instead of the design.

What is the probe's code?

From test/sv/95b_module_in_two_files.

design.sv

module top(input logic [15:0] sw, output logic [15:0] led);   // the lab as handed in
  assign led = sw;
endmodule

design_old.sv

// a backup the student kept next to the real file (lab4_old.sv): the same module name, an older body
module top(input logic [15:0] sw, output logic [15:0] led);
  assign led = ~sw;
endmodule

tb.sv

module tb;
  reg [15:0] sw = 16'h0000;
  wire [15:0] led;
  integer i;
  top dut(.sw(sw), .led(led));
  initial begin
    for (i = 0; i < 256; i = i + 1) begin
      sw = i * 16'h0101; #1
      if (led !== sw) begin $display("FAIL: led=%h for sw=%h: the backup module was built", led, sw); $finish; end
    end
    $display("PASS"); $finish;
  end
endmodule
